# RedRiver Portfolio

Personal portfolio site for RedRiveRR: a minimal status page with public GitHub projects sorted by star count.

## Structure

- `index.html`, `styles.css`, `app.js` - the static site
- `site-config.js` - site settings
- `workers/` - background worker code
- `assets/` - images and icons

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
